# Databases Coursework

Учебные работы, выполненные в рамках университетского курса «Базы данных».

Репозиторий содержит работы по проектированию реляционных баз данных, SQL, анализу данных и оптимизации запросов в PostgreSQL.

## Assignments

### Assignment 1 — Hospital Database

Проектирование ER-модели и реализация реляционной базы данных больничной информационной системы в PostgreSQL.

Разработка сложных SQL-запросов и оптимизация их выполнения с использованием индексов и `EXPLAIN`.
